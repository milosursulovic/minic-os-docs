Pre-built downloads

MiniC OS is moving fast — these are snapshots, not versioned releases, and they lag behind master by however long it's been since the last rebuild. For the actual latest, build from source instead. These exist for trying it out without a toolchain on hand yet.

Kernel — raw image

A multiboot1 kernel image — boots to 64-bit long mode, real interrupts, ring3 processes, a filesystem, the native API. Run it with qemu-system-x86_64 -kernel minic-kernel.elf. QEMU understands multiboot1 natively, so this is QEMU-only — for anything else, use the bootable ISO instead.

.elf, ~70 KB

Kernel — bootable ISO

The same kernel, packaged behind a real GRUB2 bootloader (the kernel's multiboot1-compliant, so GRUB chainloads it directly) — boots in VirtualBox, VMware, or from a USB stick on real hardware, not just QEMU. See Getting Started for VirtualBox setup.

None of these are code-signed or notarized — your browser or hypervisor may warn about an unrecognized file. That's expected for a small hobby project's own build, not a sign anything's wrong; build from source instead if you'd rather not see that warning.

Building it yourself

MiniC OS is hand-written in freestanding C and built with an ordinary Linux GCC toolchain (gcc/as/ld/ objcopy) — no separate compiler checkout needed — see Getting Started for the full setup. It's one script once the toolchain is in place: 

./build.sh          # kernel.elf
./build.sh iso       # + a bootable minic-os.iso
